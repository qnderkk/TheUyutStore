# Heart&Craft — Интернет-магазин домашней утвари и товаров для кухни

**Heart&Craft** — это современный и удобный веб-сервис, предназначенный для продажи широкого ассортимента качественной домашней утвари, посуды, аксессуаров для кухни и предметов интерьера. Мы стремимся сделать процесс обустройства быта простым, приятным и вдохновляющим.

---

### 🎯 Назначение проекта

Главная цель сервиса — сделать особенной площадкой для покупателей, которые ценят уют, качество и функциональность в своем доме. Проект решает следующие ключевые задачи:
*   **Для покупателей:** Предоставить удобный каталог с описаниями и фотографиями, чтобы легко найти и выбрать нужный товар.
*   **Общая задача:** Создать вдохновляющее пространство, где пользователи не только покупают, но и черпают идеи для обустройства своего дома.

---

### 🚀 Основной функционал

*   **Для пользователей:**
    *   Каталог товаров с фильтрацией по категориям, цене, и т.д.
    *   Умный поиск по сайту.
    *   Личный кабинет с историей заказов.
    *   Корзина с возможностью оформления заказа в несколько кликов.

---

### 👥 Целевая аудитория

Сервис ориентирован на широкую, но конкретную аудиторию:

1.  **Молодые семьи и пары,** обустраивающие свой первый или новый дом.
2.  **Любители готовки и кулинарии,** ищущие профессиональные и качественные инструменты для кухни.
3.  **Практичные домовладельцы,** желающие обновить или пополнить свой арсенал домашней утвари.
4.  **Люди, ценящие эстетику,** которые уделяют внимание дизайну и гармонии в интерьере.

---

### ✅ Ожидаемые результаты и ключевые метрики

Успешная реализованный веб-сервис, включающий все необходимые функции для удобного и быстрого поиска товаров.
